# Phase Roadmap

## Phase 1: Rapid MVP Prototype

Current phase. Build a local web app with a simple chat assistant, OpenAI API integration, a local FYEC100 knowledge base, guardrails, academic integrity guidance, and basic documentation.

## Phase 2: Enterprise Integrated Deployment

Started. Prepare for institutional deployment with Moodle embedding, configurable AI providers, authentication planning, hosting, monitoring, privacy review, Banner-aware support pathways, production governance, analytics, and support procedures.

Current Phase 2 pilot workspaces include:

- Human-readable HTML report set for pilot evidence, support triage, Moodle security hardening, and hosted deployment readiness.
- Knowledge base review workspace for FYEC100 content sections, proposed updates, approvals, and release notes.
- Pilot feedback inbox with filters by category, owner, priority, mode, and escalation type.
- Moodle embed preview studio for student, lecturer, LMS administrator, iframe, Moodle block, and future LTI rehearsal.
- Pre-pilot go-live dashboard showing ready, needs review, or blocked status for controlled pilot launch checks.
- Role-based admin views for project sponsor, project lead, LMS administrator, developer, and system administrator.
- Pilot decision packet generator with a sponsor-ready HTML export.
- Moodle pilot session console for dry runs, controlled student pilot checks, and post-session review.
- Production hardening checklist dashboard for hosting, frame security, admin protection, provider secrets, and support readiness.
- Hosted pilot deployment pack for Windows VM handoff, including environment wizard, Moodle copy center, export center, and HTML hosting runbook.
- Windows VM deployment automation pack with PowerShell starter scripts, service guidance, and preflight checks.
- Moodle pilot launch pack with placement guide, student checklist, testing scripts, and launch communications.
- Pilot monitoring and incident response pack with support signals, incident levels, response workflow, and stop-pilot triggers.
- Enterprise LTI 1.3 implementation pack with Moodle platform values, implementation stages, endpoint list, and launch validation checklist.
- Windows VM production readiness layer with readiness API, IIS reverse proxy pack, Windows service configuration pack, and deployment acceptance checklist.
- Pilot governance and approval layer with approval workflow, risk register, privacy/data handling pack, and change-control log.
- Student-facing pilot readiness layer with welcome page, responsible AI guide, feedback follow-up, and accessibility/usability test surface.
- LTI technical implementation layer with OIDC/launch validation plan, admin configuration, and security/audit pack.

## Phase 3: Advanced AI Learning Ecosystem

Future phase. Expand toward personalized learning support, proactive student success nudges, richer analytics, multilingual support, adaptive learning resources, and broader student services integration.
