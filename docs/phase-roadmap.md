# Phase Roadmap

## Phase 1: Rapid MVP Prototype

Current phase. Build a local web app with a simple chat assistant, OpenAI API integration, a local FYEC100 knowledge base, guardrails, academic integrity guidance, and basic documentation.

## Phase 2: Enterprise Integrated Deployment

Started. Prepare for institutional deployment with Moodle embedding, configurable AI providers, authentication planning, hosting, monitoring, privacy review, Banner-aware support pathways, production governance, analytics, and support procedures.

Current Phase 2 pilot workspaces include:

- Human-readable HTML report set for pilot evidence, support triage, Moodle security hardening, and hosted deployment readiness.
- Knowledge base review workspace for FYEC100 content sections, proposed updates, approvals, and release notes.
- Pilot feedback inbox with filters by category, owner, priority, mode, and escalation type.
- Moodle embed preview studio for student, lecturer, LMS administrator, iframe, Moodle block, and future LTI rehearsal.
- Pre-pilot go-live dashboard showing ready, needs review, or blocked status for controlled pilot launch checks.

## Phase 3: Advanced AI Learning Ecosystem

Future phase. Expand toward personalized learning support, proactive student success nudges, richer analytics, multilingual support, adaptive learning resources, and broader student services integration.
